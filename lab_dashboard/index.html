What this dashboard is

This is not a live Cursor telemetry feed — it merges committed workflow history with optional manual Cursor spend entries (lab_dashboard/cursor_usage.jsonl) plus local runner events (lab_dashboard/agent_events.jsonl) and optional Cursor stop hook rows (lab_dashboard/cursor_hook_events.jsonl) so you have a lightweight static page to watch trends after each push or deploy bundle.

  • Run sequences through the terminal:
    .venv/bin/python scripts/fe_ml_lab_runner.py learning (defaults to smoke) — avoids parking a long Composer session.
  • Add a Cursor bill line:
    {"ts":"2026-05-04T01:02:03Z","usd":12.34,"note":"Monthly invoice slice"}
  • Set FE_ML_LAB_SPARED_USD when kicking off learner runs if you want a heuristic “USD not spent in-chat” tally.
